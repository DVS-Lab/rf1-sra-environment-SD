# Figure 1 | PM₂.₅ and financial vulnerability

[SVG](Figure-1.svg) · [PDF](Figure-1.pdf) · [PNG](Figure-1.png) · [Plotted values](plotted-values.tsv)

**Caption.** The association between fine particulate matter and financial vulnerability weakens with perceived support. The curve shows the estimated change in Financial Exploitation Vulnerability Scale (FEVS) score per 1 µg/m³ increase in PM₂.₅ across corrected Multidimensional Scale of Perceived Social Support (MSPSS) scores. Shading is the pointwise 95% interval using HC3 standard errors; the horizontal line marks zero. The model accounts for age and gender (N = 97).

This is the primary linear model only. The quadratic sensitivity remains in supplemental Table S2B, not in this figure. Behavioral only: no NIfTI applies.
